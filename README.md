Sorcero is a dedicated custom game launcher for Warhammer 40,000: Tacticus designed to enhance the gameplay experience with quality-of-life features like themes, multi-account support, and built-in live game data (such as token timers and roster info) via the public Tacticus API. This repository serves as the official host for all Sorcero release binaries.

## Features

* Multi-Account Support: Easily manage and switch between multiple Tacticus accounts.
* Public API Key Functionality: Automatically keeps your roster up to date and loads live token timers.
* 50+ Warhammer 40,000 Faction Themes: Customize your look with over 50 faction-inspired themes, complete with Light and Dark modes.
* Replay Analyzer: Track total damage dealt and inspect detailed breakdowns of individual damage from characters, bosses, and enemies.
* Privacy-First & Fully Local: Operates entirely on your desktop without requiring online account sign-ups or external data uploads.
* Active Development: Much more functionality to come in future updates!

## Download & Installation (Windows)

Currently, Sorcero is available natively for Windows 10/11 (64-bit). However, macOS and Linux support is planned for a future update.

1. Install Tacticus from the official website [here](https://hub.tacticusgame.com/download).
2. Once Tacticus is installed, go to the Releases section on the right side of this repository.
3. Download the latest Windows release bundle (.exe installer or portable .zip).
4. Extract the contents (if downloading a ZIP), then run the installer to install Sorcero.

*Note on Security Warnings:* Because Sorcero is an open-source/indie desktop application without an expensive EV code-signing certificate, Windows Defender SmartScreen may display a warning ("Windows protected your PC") upon opening the file. This is expected for newly released executables. You can safely launch the application by clicking "More info" and then selecting "Run anyway". Additional anti-virus software like Norton, Malwarebytes, etc. may also perform a similar warning. As always, software downloaded from the internet should always be verified, and you should trust the source you are downloading it from. Do not run executables for this application if they were acquired from anywhere other than this repository or directly from me.
